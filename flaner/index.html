Pensé pour le français–turc.

Le français–turc est le réglage de départ. Les consignes du modèle restent modifiables : remplacez les langues, le niveau, le type d’explication ou le format des exemples. Avec un modèle Ollama adapté, Flâner peut accompagner d’autres combinaisons linguistiques.

UN SEUL FICHIER, VOTRE MODÈLE

Ollama et Anki,
dans le HTML local.

Sur le Web, Flâner utilise Gemini Nano. Pour le français–turc avec Ollama et l’envoi vers Anki, téléchargez le fichier HTML autonome. Aucune application Windows à installer pour Flâner.

FLÂNER LOCAL

Télécharger, ouvrir, configurer

Le fichier contient son interface et ses bibliothèques. Servez ce fichier sur localhost comme indiqué dans son aide, puis ouvrez-le dans Chrome. Le menu d’aide explique les autorisations locales Ollama et AnkiConnect : télécharger le fichier ne contourne pas les règles CORS du navigateur.

Télécharger flaner.html ↓

Si Nano n’est pas disponible depuis un fichier, servez ce même HTML sur localhost, comme expliqué dans l’aide. Nano reste soumis aux conditions de Chrome.

INSTALLER OLLAMA

Votre modèle en trois étapes

Télécharger Ollama ↗

2. Téléchargez le modèle dans votre terminal :

3. Dans le HTML Flâner, choisissez Ollama. Réglez OLLAMA_ORIGINS selon l’aide, puis cliquez sur Bağlan. Pour Anki, installez AnkiConnect et ajoutez l’origine locale dans webCorsOriginList. L’interface de l’outil est en turc.

EN PRATIQUE

Deux façons
de flâner.

Puis-je adapter les langues ?

Oui. Les consignes générales et celles du dictionnaire sont modifiables. Le français–turc est le point de départ avec Ollama ; choisissez un modèle adapté à vos langues. Nano reste limité aux langues prises en charge par Chrome.

Où sont mes conversations ?

Dans le localStorage de votre navigateur. Web, fichier et localhost peuvent avoir des historiques distincts. Utilisez Yedekle et İçe aktar pour sauvegarder et transférer vos conversations.

Et sans Internet ?

Le HTML n’a pas de dépendance externe. Les modèles doivent avoir été téléchargés auparavant et rester sur l’appareil. Le Web peut conserver son interface hors ligne après une première visite. Anki et Ollama doivent être ouverts localement si vous les utilisez.

Anki fonctionne-t-il sur le Web ?

Le bouton Anki est réservé au HTML local. Il nécessite AnkiConnect, Anki ouvert et les autorisations d’origine décrites dans l’aide du fichier.
