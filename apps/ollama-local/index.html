Yerelde, internetsiz.

Bu HTML’in dış bağımlılığı yok. Dosyayı indir; Ollama ve indirilmiş bir model açıkken kullan. Cloud etiketli veya uzak sunucudaki modeller internetsiz çalışmaz. Anki için masaüstü Anki ve AnkiConnect açık olmalı.

Dosyaya çift tıklayınca tarayıcı erişimi veya geçmiş kaydı sorun çıkarırsa HTML’in bulunduğu klasörde aşağıdaki komutu çalıştır, sonra http://127.0.0.1:8080/ollama-local.html adresini aç:

python -m http.server 8080 --bind 127.0.0.1

Ollama 403 / CORS — Windows: “No Access-Control-Allow-Origin” hatası, Ollama’nın bu siteye henüz izin vermediğini gösterir. Önce Ollama’yı sistem tepsisindeki simgesinden tamamen kapat. Ardından PowerShell’i aç ve aşağıdaki üç komutu sırayla çalıştır. Mevcut özel OLLAMA_ORIGINS ayarın varsa kullandığın diğer adresleri de aşağıdaki virgülle ayrılan listeye ekle.

$env:OLLAMA_ORIGINS = "https://suatatan.com,https://www.suatatan.com,http://localhost:8080,http://127.0.0.1:8080"

[Environment]::SetEnvironmentVariable("OLLAMA_ORIGINS", $env:OLLAMA_ORIGINS, "User")

ollama serve

Bu komutlar izni hem bu PowerShell oturumuna uygular hem sonraki açılışlar için kullanıcı ayarına kaydeder. PowerShell penceresi açık kalsın. Sonra bu sayfayı yenile veya Bağlan düğmesine bas; model listesi yeniden alınır. Chrome/Edge yerel ağ erişim izni sorarsa izin ver.

“Address already in use” hatası görürsen eski Ollama süreci hâlâ çalışıyordur; tamamen kapattıktan sonra ollama serve komutunu yeniden çalıştır. Doğrudan HTML dosyasına çift tıklayarak kullanacaksan izin listesine ayrıca null ekleyebilirsin; yerel HTTP adresiyle kullanımda buna gerek yok. Ollama’nın internete açılması gerekmez; OLLAMA_HOST ayarını değiştirme.

Anki CORS: Anki → Araçlar → Eklentiler → AnkiConnect → Yapılandırma. Mevcut webCorsOriginList listene kullandığın origin’i ekle; Anki’yi yeniden başlat. Örnek (yalnızca ilgili alan):

"webCorsOriginList": ["http://localhost", "http://127.0.0.1:8080", "https://suatatan.com", "https://www.suatatan.com", "null"]

Bu sayfanın origin’i: . Chrome/Edge yerel ağ erişim izni sorarsa izin ver. HTTPS sayfasından localhost erişimi tarayıcı politikasına bağlıdır; başarısızsa indirilen HTML’i yerel HTTP adresinden aç.

Çevrimdışı site: İnternet varken bu sayfayı bir kez aç ve sol menüde “Çevrimdışı hazır” yazısını bekle. Ardından bu adresi yer imlerine ekle; internet olmasa da aynı tarayıcıdan yeniden açabilirsin. Ollama ve indirilmiş yerel model açık olmalı. Anki aktarımı da yerelde çalışır. Tarayıcı site verilerini temizlerse çevrimdışı önbellek silinir. Service worker yalnız bu uygulamanın sayfasını saklar; Ollama/Anki isteklerini önbelleğe almaz.

Biçimlendirme: Başlıklar, kalın/italik yazılar, listeler, tablolar ve kod blokları Markdown olarak gösterilir. Güvenli temel HTML de desteklenir; betikler, gömülü sayfalar ve uzak resimler çalıştırılmaz. Kopyala düğmesi Markdown kaynağını kopyalar.

Modeller: Açılışta Ollama’daki modeller otomatik listelenir ve diskteki boyutlarına göre sıralanır. İlk kullanımda en küçük yerel model seçilir. Seçimin tüm sohbetlerde ve sonraki açılışlarda korunur; model listede yoksa başka modele sessizce geçilmez. Ollama kapalıysa açtıktan sonra Bağlan düğmesine bas.

Geçmiş: localStorage tarayıcı/profil/origin’e bağlıdır. Dosya sürümü ve site sürümü ayrı geçmiş tutabilir. Gizli pencere veya site verilerini temizlemek geçmişi silebilir; Yedekle düğmesini kullan. Aynı anda bir sekmede çalıştır. API anahtarı yedeklenmez.

Thinking yalnız destekleyen modellerde kontrol edilir; bazı modeller kapatmayı desteklemez. Model hatası gelirse varsayılanı seç. Modelin bağlam penceresini aşan sohbetlerde yeni sohbet aç veya num_ctx değerini modelin desteklediği ölçüde artır.
