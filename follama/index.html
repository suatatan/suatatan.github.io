LE PLUS SIMPLE · WINDOWS

L’assistant Follama

Installez Follama, puis ouvrez Ollama + Gemma 3 kurulumu dans le menu. Si Ollama manque, l’assistant propose son installation officielle. Après votre accord et la fin de l’installation, il télécharge gemma3:4b.

Vous voyez la progression. Vos modèles existants sont conservés. Le modèle représente environ 3,4 Go, auxquels s’ajoutent Ollama et les fichiers temporaires.

UNE AUTRE PORTE D’ENTRÉE

Le modèle de Chrome,
quand il est disponible.

La version Web propose aussi la Chrome Prompt API / Gemini Nano, indépendamment d’Ollama. Dans Follama pour Windows, Chrome’da aç ouvre la même interface dans Google Chrome.

Choisissez le moteur Chrome puis Nano hazırla / indir. Le premier téléchargement nécessite Internet et un appareil compatible. Le diagnostic intégré distingue une API absente, un modèle à télécharger et des options linguistiques non disponibles.

Pour le français–turc, choisissez Ollama. Le mode Chrome de Follama utilise le français et l’anglais ; le turc n’est pas officiellement pris en charge par Gemini Nano.

EN PRATIQUE

Quelques réponses,
avant de commencer.

Est-ce utilisable sans Internet ?

Oui, avec un modèle local déjà téléchargé. Le premier téléchargement d’Ollama, de Gemma ou du modèle Chrome demande Internet. Les modèles Ollama marqués « cloud » utilisent un service distant.

Faut-il installer Anki ?

Uniquement pour envoyer des cartes. Installez Anki Desktop et l’extension AnkiConnect, puis gardez Anki ouvert. Follama vous laisse choisir le paquet et le type de note avant l’envoi. Une clé AnkiConnect, si vous en utilisez une, se renseigne dans les paramètres.

Où restent mes conversations ?

Sur votre appareil. La version Web utilise le stockage local du navigateur. La version Electron conserve aussi un fichier local partagé avec sa fenêtre Chrome. Exportez un JSON avec « Yedekle » pour garder une copie et utilisez « İçe aktar » pour la restaurer.

Puis-je changer les langues ou les consignes ?

Oui. Les consignes générales et celles du mode dictionnaire sont modifiables. Choisissez un modèle qui prend en charge vos langues. Les consignes Chrome sont séparées, car ses langues et paramètres disponibles diffèrent de ceux d’Ollama.

Le modèle est-il livré dans Follama ?

Non. L’application et le modèle sont séparés. L’assistant peut installer Ollama et télécharger gemma3:4b après votre accord. Vous pouvez également garder votre installation Ollama et vos modèles actuels.
